# Workout Tracker

A simple workout tracker: generate a workout from the muscles you pick, log weight and reps,
rest timer, history, and a cheering mascot. Plain HTML/CSS/JS with no build step.
Data is saved in your browser (localStorage).

Live at https://rajuria.github.io/workout-tracker/

## Run locally

    python3 -m http.server 8000

Then open http://localhost:8000
