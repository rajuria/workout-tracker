Put the mascot images in this folder using these exact names
(PNG or WebP, e.g. idle.png or cheer1.webp):

  idle        -> shown on the Workout tab
  cheer1 ... cheer4  -> shown after each logged set (one picked at random;
                        you don't need all four)
  celebrate   -> shown on the finish screen

Missing images fall back to any other mascot image, or to a drawn placeholder.
Transparent PNG/WebP, roughly 400x480 px, looks best.
After adding images, commit and push them to GitHub.
